    Test your own AI

    1. Add your own tricky questions to evals/cases.js. For each one, write what a good answer must (or must not) say.
    2. Run them against your model:
      PRODHEALTH_API_KEY=… node evals/run.mjs \
  --endpoint https://api.example.com/v1/chat/completions \
  --model my-new-model \
  --baseline evals/results/baseline.json \
  --out evals/results/candidate.json
    3. If something important breaks, the command fails, so it can stop a release automatically. Open More → Load new version results here to look through the answers.
